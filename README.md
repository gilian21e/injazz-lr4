# InJazz — лендинг джазовой кофейни (ЛР4, Информатика)

Одностраничный сайт джазовой кофейни InJazz (Санкт-Петербург), созданный с помощью LLM по одному и тому же промту.

| Сайт | Модель | Папка |
|---|---|---|
| Основной | ChatGPT (OpenAI) + правки агента Claude Code | `/` |
| Для сравнения | Qwen3.7-Plus | `/qwen/` |

Структура: `index.html` + `css/style.css` в каждой папке.

Демо-данные (цены, телефон, фото с Unsplash) обозначены на сайте и не являются реальными.
